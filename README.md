# FitLog

FitLog is a workout library app built for lifters who just want to grab a plan and go. Pick a lift from the library, read the instructions, add it to today's plan, and the app tracks your exercises, minutes, and calories as you go. No accounts, no clutter — everything lives in your browser.

## Technologies Used

- Next.js (App Router)
- React Context API
- Tailwind CSS
- lucide-react for icons

## Key Features

1. A responsive workout library you can sort by Duration, Calories, or Rating
2. Detail pages for each lift with step-by-step instructions and key specs
3. A five-lift daily cap on Today's Plan, so the list stays realistic instead of endless
4. A My Plan page with running totals for exercises, minutes, and calories
5. Mark as Done, remove, and toast confirmations for every action you take
